# 01: chmod のパーミッション

## 目的

`chmod 755` の数字が何を意味するか、計算で求められるようにする。

---

## 事前に考えてみよう

`chmod 755` の `7`, `5`, `5` はそれぞれ何を表していると思いますか？
先を読む前に自分の言葉で書いてみてください。

---

## 背景知識

パーミッションは3桁の数字で表される。左から「オーナー」「グループ」「その他」の順。

各桁の数字は以下の3権限の合計値:

| 権限     | 記号 | 数値 |
| -------- | ---- | ---- |
| 読み取り | r    | 4    |
| 書き込み | w    | 2    |
| 実行     | x    | 1    |

```
chmod 755
  7 = 4+2+1 = rwx  → オーナー（読み・書き・実行すべて可）
  5 = 4+0+1 = r-x  → グループ（読みと実行のみ）
  5 = 4+0+1 = r-x  → その他（読みと実行のみ）
```

`ls -la` の出力との対応:

```
-rwxr-xr-x  → 755
-rw-r--r--  → 644
-rw-------  → 600
```

## 実習

### Step 1: 計算練習

以下の数値を rwx 表記に変換してください（手計算で）。

```
TODO(human): 以下を変換する
  chmod 600 → オーナー:rw_  グループ:___  その他:___
  chmod 644 → オーナー:rw_  グループ:r__  その他:r__
  chmod 777 → オーナー:rwx  グループ:rwx  その他:rwx
```

### Step 2: ターミナルで確認

```bash
# ファイルを作って権限を変えながら ls -la で観察する
touch test_file.txt
ls -la test_file.txt

chmod 755 test_file.txt
ls -la test_file.txt

chmod 600 test_file.txt
ls -la test_file.txt
```

```
-rw-------  1 reo  staff  0 10月 29 00:37 test_file.txt
```

### Step 3: 理由を考える

SSH の秘密鍵ファイル（`~/.ssh/id_rsa`）には `600` が要求される。

```
まず実行ファイルではないため、全てのユーザー実行権限はいらない。
また、オーナーではないグループやユーザーが秘密鍵を閲覧できてしまうと情報漏洩につながるため。
```

## 理解の確認

`chmod 750` は何を意味するか、自分の言葉で説明できますか？
オーナーには、閲覧、書き込み、実行
グループには、閲覧のみ+実行
ユーザーには 権限を与えていない。

「グループには○○の権限があり、その他には○○の権限がない」という形で書いてみてください。
